# Métadonnées de la bibliothèque

La fenêtre **Métadonnées** centralise les informations réutilisées dans les fiches manga :

- les tags, avec leur état visible ou masqué ;
- les auteurs ;
- les séries.

Chaque onglet permet de rechercher, ajouter, renommer et supprimer ses valeurs. Une confirmation est demandée avant une suppression.

La fenêtre **Gérer le manga** regroupe les informations principales, le classement et l’emplacement des fichiers. Une fiche peut être associée à plusieurs auteurs, plusieurs tags et une série.
