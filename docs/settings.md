# Parametres

La fenetre `Parametres` regroupe les options generales, le scraping, le lecteur,
les raccourcis, les statistiques, les options developpeur et les informations
d'installation.

Les onglets qui contiennent un formulaire proposent deux actions :

- `Enregistrer` sauvegarde les valeurs et garde la fenetre ouverte. Un message
  confirme la reussite ou affiche l'erreur rencontree.
- `Enregistrer et quitter` sauvegarde les valeurs, puis ferme la fenetre
  uniquement si l'enregistrement a reussi.

Pendant l'enregistrement, les actions et le changement d'onglet sont desactives
pour eviter deux sauvegardes concurrentes.
