# v0.14.25

## Recherche de correspondance

- Les titres japonais sont désormais comparés aux titres rōmaji dans les deux sens.
- Une recherche japonaise peut lancer jusqu’à deux variantes rōmaji pertinentes, sans dépasser la limite globale de scraping.
- La translittération reconnaît mieux la construction familière `ん家` (`-n-chi`) et les variantes `gyaru` / `gal`.
