# v0.14.41

## Améliorations

- Une profondeur de `0` dans la recherche auteur poussée analyse désormais tous les mangas restants, y compris ceux chargés depuis les pages auteur découvertes pendant la même vague.
- Chaque nouvelle vague d’approfondissement réinitialise les badges `Nouveau` sans perdre l’historique des pages déjà découvertes.
- Les auteurs rejetés sans page auteur proposent maintenant le ou les mangas à l’origine du rejet dans un menu déroulant, avec ouverture normale ou dans l’espace de travail.
- Depuis le résultat enregistré d’une recherche de nouveautés, `Continuer` reprend exactement le même scan dans la vue courante. L’action apparaît uniquement pour les scans rapides ou profonds qui possèdent encore une page, et reste masquée pour le scan complet.

## Corrections

- Les cards utilisent désormais la même détection que la fiche pour signaler un manga déjà bookmarké, lu, en cours ou présent dans une liste de lecture.
- Lorsqu’une fiche a enrichi une card, son titre canonique et son URL finale sont utilisés pour reconnaître correctement les bookmarks, l’historique de lecture et les mangas déjà présents en bibliothèque.
- Les auteurs rejetés n’exposent plus de liens de page auteur supposés qui aboutissaient à une erreur 404, notamment sur nHentai.
- Le titre affiché comme preuve d’un auteur rejeté provient désormais du scraper qui a réellement produit ce libellé, au lieu du titre préféré d’une autre source fusionnée.
