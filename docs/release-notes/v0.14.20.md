# v0.14.20

## Recherche de correspondance manga

- Les titres traduits suivis d’un chapitre entre parenthèses et d’une source entre accolades sont désormais correctement analysés.
- Une œuvre n’est plus acceptée uniquement parce que le titre recherché apparaît dans une parodie ou une autre métadonnée.
- Les suffixes de release encadrés par des signes `=` ne perturbent plus la détection du chapitre.
- Un titre sans numéro reste considéré comme le chapitre 1, tandis que les compilations et hors-séries restent séparés.
