# v0.14.38

## Nouveautés

- La recherche de correspondances auteur propose désormais un mode poussé qui analyse les mangas les plus présents pour découvrir d’autres sources et pages auteur.
- La page de résultats permet de lancer le mode poussé puis de l’étendre aux mangas suivants sans retraiter ceux déjà analysés.
- La vue de l’auteur combiné réutilise en mémoire les pages déjà parcourues et rattache les nouvelles correspondances manga à leur carte d’origine, sans écrire ce cache sur le disque.
