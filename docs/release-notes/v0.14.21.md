# v0.14.21

## Listes de lecture depuis une correspondance

- Les cards de chapitre peuvent être invalidées pour préparer une liste de lecture sans supprimer les résultats de recherche.
- Les chapitres invalidés restent visibles et ouvrables, avec une apparence atténuée et une action pour les réintégrer.
- Le dialogue de création permet également d’inclure ou d’invalider chaque chapitre.
- La couverture par langue, les chapitres manquants, les remplacements et le nombre final sont recalculés selon les chapitres retenus.
