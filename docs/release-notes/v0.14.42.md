# v0.14.42

## Nouveautés

- La page des bookmarks propose maintenant un menu `Comptages` donnant accès à deux fenêtres distinctes pour les tags fréquents et les auteurs fréquents.
- Les auteurs sont regroupés avec les mêmes règles de correspondance que la recherche auteur. Le parseur de titre complète les métadonnées absentes et chaque groupe affiche une couverture issue d'un manga bookmarké.
- Un clic sur le nom d'un auteur filtre les bookmarks. Le bouton dédié ouvre sa vue auteur combinée, avec prise en charge du clic molette pour l'ouvrir dans l'espace de travail.

## Améliorations

- Les pages auteur déjà liées aux mangas bookmarkés apparaissent immédiatement dans la vue combinée, puis la recherche de correspondances standard complète les résultats en arrière-plan.
- Les comptages sont calculés hors de l'interface et conservés dans un cache incrémental : seuls les bookmarks ajoutés, modifiés ou supprimés sont resynchronisés.

## À savoir

- Les bookmarks existants doivent être rescrapés une fois pour enregistrer leurs liens auteur et les afficher immédiatement dans la vue combinée.
